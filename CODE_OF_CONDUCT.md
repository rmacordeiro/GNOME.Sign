# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be respectful, welcoming and constructive. Harassment of any kind is not tolerated.

Report unacceptable behaviour privately through GitHub's "Report content" feature or by contacting the maintainer through the email on their GitHub profile. Reports are handled confidentially.
